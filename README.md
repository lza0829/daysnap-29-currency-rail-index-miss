# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6600
# 台面 → 一键冒烟 → 周期快照有行 → 差额清单为空（或仅看最新回放批）
```

本地拆跑：

```bash
# API
cd backend && pip install -r requirements.txt
$env:夹具目录='..\fixtures'; uvicorn app.main:app --port 11600

# 前端
cd frontend && npm install && npm run dev
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜 |
| 回放核对 | 前日快照+当日流水 vs 当日快照 |
| 差额清单 | 不一致行 |
| 断档/跳变 | 缺前日镜、偏离阈值 |
| 旁置簿 | 未入账载荷 |

## 币种隔离（已落地）

全局只贯彻一种架构：**账户 + 币种 + 营业日复合键写周期快照**（未采用分镜表方案）。

- 同户同日两币种必须是**两行复合键快照**，禁止出现未标币种的单行总余额；周期快照主读可据此与「分镜表/单行总余额」口径区分。
- 跨币种禁止并键、禁止隐式折算（载荷携带 `汇率/折算额/折算币种` 等字段即旁置）；不提供任何跨币合计接口，合计不可作核销口径。
- 装载、日终抽取、快照、回放、差额、账户册同轨协同：装载写闸旁置混币；抽取/回放遇未标币种流水或快照整批**失败闭**（HTTP 409），不留半截有效镜；重抽只盖写同轨行，不压成总余额。
- 账户册 `多币种` 标记：多币种账户上未标币种的载荷禁止回退本币，防止本币有效镜吞外币净额。
- 核证接口 `GET /api/轨核证`：返回分轨余额、禁混计标记、`valid`、违规行。
- 夹具：`双币种分轨样例.json`（分轨守恒/回放分轨）、`混币旁置样例.json`（混币必旁置）、`同日并发装载样例.json`（并发不轧单行）。
- 测试：`backend/tests/`（服务层 12 项 + API 层 5 项），断言无未标币种单行总余额且回放分轨通过。
